# Atlanta Plumber For Less

Website for Atlanta Plumber For Less, built with React and Vite.

## Run Locally

**Prerequisites:** Node.js 20 or newer and npm.


1. Install dependencies with `npm install`.
2. Start the development server with `npm run dev`.
3. Create a production build with `npm run build`.

The production site is written to `dist`. Upload the contents of that folder to any static web host or web server. The build uses relative asset paths and does not require a platform-specific redirect or server runtime. No environment variables are required.
